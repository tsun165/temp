# Ghi chú cuộc họp

- Lưu tại `docs/meetings/YYYY/YYYY-MM-DD-<chu-de>.md` trong repo đang mở.
- Mục cố định: Thành phần · Nội dung chính · Quyết định · Việc cần làm.
- Việc cần làm viết dạng `- [ ] nội dung (@người)`.
- Khi tôi bảo "chốt biên bản": liệt kê các việc chưa tick để tôi duyệt, tạo issue
  cho những việc được duyệt theo skill `github-tasks` (thêm vào Project nếu repo dùng
  Project), rồi thay dòng đó bằng link issue.
