# Web/Node: dùng pnpm thay npm
- Khi dựng hoặc làm web/Node project, dùng pnpm thay npm/npx: `pnpm install`, `pnpm add [-D]`,
  `pnpm run <script>`, `pnpm dlx` (thay `npx`), `pnpm create <tool>` (thay `npm create`).
- Repo có sẵn `package-lock.json` hoặc `yarn.lock` (thường là repo nhóm): không tự chuyển sang pnpm, hỏi tôi trước.
